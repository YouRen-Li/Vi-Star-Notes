# Nuxt介绍

Nuxt 是一个免费的[开源框架，它以直观且可扩展的方式使用](https://github.com/nuxt/nuxt)[Vue.js](https://vuejs.org/)创建类型安全、高性能和生产级的全栈 Web 应用程序和网站。
Nuxt官网：https://nuxt.com/docs/4.x/getting-started/introduction

1.核心定位

- Nuxt 就是 **基于 Vue 的 SSR（服务端渲染）框架**，但它不只做 SSR。
- Nuxt = Vue 的全家桶升级包。
- 默认帮你搞定 **SSR、路由、打包、SEO、状态管理集成**。
- 你写页面文件，它帮你自动变成路由和服务端可渲染的 HTML。

2.SSR（Server-Side Rendering）

- 普通 Vue 是 CSR（客户端渲染），首屏白屏 + SEO 差。
- Nuxt 在服务端先跑一遍 Vue，把 HTML 渲染好再丢给浏览器 → 首屏快、SEO 友好。
- 后续再“激活”变成 SPA。

3.不止 SSR

- **SSG（静态站点生成）**：一键打包成纯静态文件，部署到 CDN。
- **CSR（客户端渲染）**：想当普通 Vue 用也行。
- **Hybrid**：部分页面 SSR，部分 SSG/CSR。

4.为什么用 Nuxt

- 目录结构约定 → 少写配置。
- 自动路由 → 省心。
- 内置数据获取（`useAsyncData`、`fetch`）→ SSR & CSR 统一。
- 插件体系 → 第三方库集成更方便。

**Nuxt = Vue 的 SSR 框架 + 应用级框架**，核心是 SSR，但它更像是“Vue 的 Next.js”。
