## 1.类与接口的继承/实现关系

### 1.类继承类

子类继承父类的实现(属性+方法)，可以复用和重写。

关键词：**extends**

```
class Animal {
  move() {}
}
class Dog extends Animal {
  bark() {}
}
```



### 2.接口继承接口

一个接口扩展另一个接口（类型复用）

关键词**extends**

```
interface Person { name: string }
interface Employee extends Person { salary: number }
```



### 3.类实现接口

类必须实现接口定义的所有属性和方法

关键词：**implements**

```
interface Flyable { fly(): void }
class Bird implements Flyable {
  fly() { console.log("flying") }
}
```



### 4.接口继承类

接口会继承类的实例成员结构（包括private/protected）

因此，这个接口只能由该类或其子类来实现。

关键词**extends**

```
class Animal {
  protected age: number = 1
  private secret: string = "hidden"
}
interface Dog extends Animal { bark(): void }

class Husky extends Animal implements Dog {
  bark() {}
}
```



### 5.类继承类，实现其子接口

这是第四种的衍生：当接口继承了一个类（带private/protected）

新的类必须继承这个父类，才能实现这个接口。

**如果直接 `class Cat implements Dog` 会报错，因为没有 `secret` 和 `age`。）**

```
class Animal {
  protected age: number = 1
  private secret: string = "hidden"
}
interface Dog extends Animal { bark(): void }

// ✅ 只能继承 Animal 才能实现 Dog
class Husky extends Animal implements Dog {
  bark() {}
}
```
